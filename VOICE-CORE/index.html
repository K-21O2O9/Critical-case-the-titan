VOICE CORE

Fully offline-capable voice control layer for HTML applications. Uses the browser’s Web Speech API (on-device when available). No API keys, no cloud AI. Register your own commands and the assistant executes them.

How to integrate

Include the scripts and register your functions:

// After VoiceCore scripts are loaded
await VoiceCore.init();

VoiceCore.register({
  name: "activate_engines",
  phrases: ["start engines", "turn on engines", "activate propulsion"],
  action: () => { activateEngines(); },
  response: "Engines activated."
});

VoiceCore.start(); // begin listening

See README.md and the Titan integration example for a full production setup.

Offline notes

  • Web Speech API is used first. Many Chromium browsers support processLocally for true on-device recognition after the language pack is present.
  • No audio is sent to external services when on-device mode is active.
  • Speech synthesis (replies) also runs locally via the browser.
  • If you see “language not supported”: the browser lacks that speech locale. VoiceCore auto-falls back through en-US → en-GB → en and disables on-device mode if needed. You can always type commands in the panel.
  • Chrome/Edge on desktop usually work best. Firefox and some mobile browsers have limited language packs or require network for recognition.
  • For stricter offline environments you can later swap the recognition backend for Vosk / Vosklet (see README).
  • Always provide a typed fallback — the panel includes a manual input.
